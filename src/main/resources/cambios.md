# 🚀 **Nueva Versión v1.2.0 - ¡Lanzada!**

¡Estamos emocionados de anunciar la versión **v1.2.0** de nuestro proyecto! Esta versión trae algunas mejoras
importantes, correcciones de errores y nuevas características que mejorarán la experiencia de los usuarios. Aquí están
los detalles:

### 🆕 **Nuevas Características**:

- **Mejora en la codificación de los campos**: Se ha modificado la codificación de la base de datos para hacerla más
  amigable.
- **Eliminación de caracteres extraños en los campos de tipo TEXT**: Se han eliminado los caracteres asociados a los
  saltos de página en los campos de tipo TEXT.

### 🐛 **Correcciones de Errores**:

- **Se ha mejorado el control de errores**: Mejora del control de errores

### 🔧 **Mejoras**:

- **Optimización del rendimiento**: Se optimizó el procesamiento de datos, lo que resulta en una mejora significativa en
  la velocidad de las importaciones.
- **Refactorización del código**: Se refactorizó el código para hacerlo más limpio y fácil de mantener.

### 📝 **Otros Cambios**:

- Se actualizaron las dependencias a versiones más recientes para mejorar la seguridad y el rendimiento.
- Se mejoró la documentación, ahora más detallada, para facilitar la configuración y el uso del proyecto.
