# Release 7.4.3

## Corrección de publicación

Esta versión sustituye a 7.4.2 para uso operativo.

- `hibernate.persistence.entry_flush_window` vuelve a ser realmente opcional.
- Si la clave no figura en `hibernate.properties`, se aplica `0`, que conserva el comportamiento de persistencia por lotes sin una ventana adicional de `flush/clear`.
- El valor `0` es válido; solo se rechazan valores negativos.
- La corrección evita el fallo de las pruebas de persistencia y de instalaciones existentes que no tienen esa clave configurada.

## Validación

- `mvn spotless:check test`
- Empaquetado de los cuatro perfiles: `con-filtros-local`, `con-filtros-internet`, `sin-filtros-local` y `sin-filtros-internet`.
