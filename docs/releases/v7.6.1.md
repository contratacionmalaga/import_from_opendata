# Release 7.6.1

## Logs únicos por ejecución

- Cada lanzamiento recibe un identificador único con formato
  `yyyyMMdd_HHmmss_<id>`.
- El identificador se comparte entre el log del lanzador, el log operativo de la
  aplicación, el log de errores y el log de Hibernate.
- Los lanzadores de Windows y Linux/macOS pasan el identificador y el directorio
  de logs a Java, por lo que las importaciones simultáneas nunca escriben en el
  mismo fichero.

Ejemplo de una ejecución:

```text
logs/importacion_20260926_193953_a1b2c3d4.log
logs/import-from-opendata_20260926_193953_a1b2c3d4.log
logs/import-from-opendata_error_20260926_193953_a1b2c3d4.log
logs/import-from-opendata_hibernate_20260926_193953_a1b2c3d4.log
```

## Gestión de incidencias

- La consola sigue mostrando un mensaje breve sin pila Java y remite al log
  técnico correspondiente a la ejecución.
- El correo de soporte incorpora el nombre exacto del archivo de errores cuando
  la importación se inicia desde uno de los lanzadores.

## Validación

- Suite Maven: 72 pruebas superadas; 2 pruebas de integración de MariaDB
  omitidas por no estar configurada su conexión de integración.
- Simulación PowerShell con `-DryRun -SkipConfirmation`: comprobada la creación
  y propagación del identificador único al comando Java.
