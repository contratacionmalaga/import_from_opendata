# Release 7.6.2

## Simplificación de logs

- Se elimina el identificador interno de incidencia (`IMP-...`) de la consola y
  de todos los archivos de log.
- La identificación de cada importación se mantiene mediante el nombre único de
  sus archivos de ejecución.
- El identificador interno continúa disponible únicamente en el correo de
  soporte, donde aporta valor para el diagnóstico de una incidencia.

## Validación

- Se actualiza la prueba de configuración de Logback para impedir que el
  identificador de incidencia vuelva a aparecer en los patrones de log.
