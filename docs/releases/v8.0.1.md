# Release 8.0.1

## Cierre correcto de importaciones locales

Un feed ATOM local puede incluir un enlace next hacia un fichero posterior que no forma parte del corpus disponible en disco. A partir de esta versión, ese caso finaliza el parseo local correctamente tras procesar el último feed accesible.

La consola informa:

    Fin del parseo local: el siguiente feed no está disponible en el directorio configurado.

No genera error, correo de soporte ni código de salida fallido.

## Casos que siguen siendo errores

- El fichero inicial configurado no existe.
- El enlace next es inválido o intenta salir del directorio local permitido.
- El fichero siguiente existe, pero es ilegible o no es un fichero regular.
- El XML ATOM no puede procesarse.
- Los enlaces forman un ciclo.
- En modo Internet, un feed next inaccesible continúa siendo un error tras los reintentos configurados.

## Validación

- Prueba de navegación añadida para el final normal de un corpus local incompleto.
- Suite Maven: 79 pruebas superadas; 2 pruebas de integración MariaDB omitidas
  al no haber una conexión de integración configurada.
