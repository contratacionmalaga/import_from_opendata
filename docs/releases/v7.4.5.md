# Release 7.4.5

## Actualización de dependencias

El proyecto actualiza su parent Maven a `jarios-parent` 1.0.14, que centraliza estas actualizaciones compatibles:

- Logback: 1.6.3 a 1.6.4.
- Jackson Core, Databind y JSR-310: 2.22.2 a 2.22.3.
- Hibernate Core y el módulo `hibernate-hikaricp`: 7.4.5.Final a 7.4.10.Final.
- jsoup: 1.23.1 a 1.23.2.
- Lombok: 1.18.46 a 1.18.48.
- SLF4J API: 2.0.18 a 2.0.20.

No se incluyen saltos de versión mayor ni versiones preliminares.
La actualización no modifica la versión independiente de `com.zaxxer:HikariCP`.

## Validación

- Pruebas Maven y comprobación de formato.
- Empaquetado de los cuatro perfiles operativos.
- Verificación del árbol de dependencias resuelto.
