# Release 7.6.0

## Corrección de plazos ATOM

- Se corrige el mapeo de `TenderingProcess/DocumentAvailabilityPeriod`: desde esta versión se
  persiste en `document_availability_period` y deja de recibir por error el plazo de presentación
  de ofertas.
- Se incorpora `TenderingProcess/ParticipationRequestReceptionPeriod` en la entidad y en la tabla
  `tendering_process` como `participation_request_reception_period`.
- Se añade una prueba que verifica que disponibilidad de documentos, presentación de ofertas y
  recepción de solicitudes de participación se persisten como tres fechas independientes.

## Auditoría ATOM

- Se incorpora una auditoría completa del fichero de contratos mayores, con 493 `entry`, rutas y
  atributos analizados frente a los mappers y entidades del proyecto.
- La Fase 1 de la auditoría queda marcada como realizada.
- Se documentan las decisiones de alcance: no se incorporarán `ActivityCode`, país, código de país
  ni fax del órgano de contratación; se conserva el modelo escalar actual para subcontratación e
  identificadores mientras el origen aporte una única instancia efectiva.

## Migración de base de datos

Antes de desplegar la versión, aplicar:

```text
docs/migrations/v7.6.0/01_add_participation_request_reception_period.sql
```

La corrección de `document_availability_period` no requiere una columna nueva. Para rectificar
valores históricos, volver a importar los ATOM afectados tras aplicar la migración y desplegar
esta versión.

## Validación

- `MapperTenderingProcessTest` verifica los tres plazos con valores diferentes.
- Se ejecutan las pruebas de cobertura de mappers y de consistencia de entidades.
