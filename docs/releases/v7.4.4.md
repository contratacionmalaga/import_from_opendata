# Release 7.4.4

## Resumen de ejecución

- El encabezado de `importar_atoms.ps1` deja de repetir el directorio operativo, la ruta de properties y las opciones Java.
- Esos datos se muestran una sola vez, dentro de los bloques de la ejecución seleccionada y de recursos aplicados.
- La configuración de memoria se mantiene en `properties/runtime.properties`, para que cada entorno declare explícitamente sus opciones Java.

## Validación

- Análisis sintáctico de PowerShell.
- Ejecución de humo cancelada antes de Java contra el directorio operativo con `sin_filtros / local / MAYORES`.
