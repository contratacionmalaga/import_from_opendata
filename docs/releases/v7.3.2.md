# Release 7.3.2

Fecha: 2026-09-09
Rama: `jarp/versiona-properties-example-v7.3.2`

## Cambios

- Se versionan plantillas `properties/*.properties.example` para preparar entornos descargados desde GitHub sin incluir credenciales reales.
- Se mantienen ignorados los ficheros reales `properties/*.properties`, que pueden contener credenciales JDBC, credenciales SMTP, direcciones de correo y rutas locales.
- Se anade `properties/runtime.properties.example` para documentar la configuracion JVM usada por los lanzadores.
- Se anade `properties/jakarta_filtro.properties.example` como plantilla opcional para la conexion JDBC de filtros SQL.
- Se actualiza el README con instrucciones de copia de plantillas y configuracion por entorno.
- Se actualiza la version Maven del aplicativo a `7.3.2`.

Los valores sensibles se sustituyen por marcadores `CHANGE_ME_*`. No se versionan los ficheros reales `properties/*.properties`.
