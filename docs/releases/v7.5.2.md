# Release 7.5.2

## Auditoría temporal

- `created_at` y `updated_at` permanecen únicamente en `entry`.
- En actualizaciones desde Internet se conserva el `created_at` original del expediente y se renueva `updated_at`.
- Se retiran ambos campos de las 32 entidades restantes, cuyos grafos se recrean al reemplazar un expediente.

## Migración de base de datos

Los scripts están en `docs/migrations/v7.5.2/`:

- `01_precheck.sql` comprueba las columnas antes de intervenir.
- `02_drop_child_audit_columns.sql` elimina las 64 columnas de las tablas afectadas, sin modificar `entry`.

## Validación

- Pruebas de persistencia que preservan `Entry.created_at` durante un reemplazo.
- Prueba que garantiza que `Entry` es la única entidad auditada.
