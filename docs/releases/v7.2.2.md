# Release 7.2.2

Fecha: 2026-08-19
Rama: `jarp/fix-estadisticas-v7.2.2`

## Cambios

- Se corrige la estadistica de Malaga para informar `n_entries` con el numero de entradas preparadas para persistencia.
- Se elimina del modelo JPA el campo `n_registros_historicos_eliminar`, ya que no representa registros historicos persistidos y los borrados se contabilizan mediante `n_deleted_entries`.
- Se simplifica `HistoricoTotales` para no transportar ni sumar el contador `eliminar`.
- El resumen de Malaga deja de mostrar `Entry ELIMINADOS`.
- Se anade cobertura de test para asegurar que `n_entries` llega al plan de persistencia.
- Se actualiza la version Maven del aplicativo a `7.2.2`.

## Impacto operativo

Si el esquema se valida con `hibernate.hbm2ddl.auto=validate`, la tabla `estadistica` no debe contener ya la columna:

```sql
n_registros_historicos_eliminar
```

Los borrados detectados por tombstones Atom siguen quedando representados por:

```sql
n_deleted_entries
```

Migracion recomendada en MariaDB:

```sql
ALTER TABLE estadistica DROP COLUMN n_registros_historicos_eliminar;
```
