# Release 7.5.1

## Ejecución autónoma del importador

- Se incorpora el interruptor `-SkipConfirmation` en `importar_atoms.ps1`.
- El plan completo continúa mostrándose y la activación de esta opción queda registrada en el log del lanzador.
- La confirmación manual mediante `I` se conserva como comportamiento predeterminado.

## Automatización en Windows

El script puede ejecutarse desde el Programador de tareas o un servicio con PowerShell en modo `-NonInteractive` y el argumento `-SkipConfirmation`.

```powershell
powershell.exe -NoProfile -NonInteractive -File "C:\java\ejecutables\import-from-opendata-ejecutables\importar_atoms.ps1" `
  -Grupo sin_filtros `
  -Mode local `
  -TipoSindicacion MAYORES `
  -SkipConfirmation
```
