# Release 8.2.2

Fecha: 14/10/2026. Rama: `jarp/fix-schema-reset-8.2.2`.

Al ejecutar una carga local con `-CreateSchemaFirstRun`, MariaDB podía impedir el borrado
de tablas referenciadas por claves foráneas heredadas. Hibernate continuaba tras los errores
DDL y la comprobación de carga local encontraba expedientes antiguos en el esquema parcialmente
reconstruido. Esta versión retira las FK internas usando sus nombres reales antes de `create`.

Solo actúa para `create`/`create-drop` en MariaDB y solo entre tablas del modelo Java.
Si detecta una referencia desde otra tabla o esquema, detiene la reconstrucción antes de
modificar restricciones. Hibernate detiene el arranque ante cualquier error DDL.
La comprobación de integridad referencial permanece activada para las importaciones.

Las 33 tablas del modelo se recrean; las tablas externas y las vistas se conservan.
Se mantienen los generadores UUID v7, identificadores externos, conservación de identidad
en actualizaciones y selección automática de bases incorporados en las versiones anteriores.

[Guía completa de comandos](v8.2.2/README.md).

## Vistas de Málaga

Por petición del usuario se eliminan `feed_updated_at` y `log_updated_at` de `expedientes`,
y `created_at`/`updated_at` de `vista_expedientes_importacion`. Esas referencias impedían
consultarlas después de reconstruir las tablas desde el modelo Java.
No se incorporan columnas de auditoría nuevas al modelo.
[SQL aplicado y reversión](../migrations/v8.2.2/README.md).

## Validación

87 pruebas Java: cero fallos/errores, dos pruebas manuales omitidas. Incluye cinco pruebas
nativas en `opendata_malaga_testing:3306` y siete casos del lanzador con Java simulado.

El usuario autorizó reconstruir `opendata_malaga:3306` desde cero. Se retiraron 51 FK heredadas;
las 33 tablas se recrearon y validaron. La prueba insertó 33 entidades y verificó sus IDs y
42 referencias UUID nativos v7, revirtiendo después la transacción. Una segunda reconstrucción
con las 42 FK actuales también pasó. Las dos tablas externas conservaron su contenido, y las
26 vistas admiten consultas tras el ajuste solicitado. El destino queda vacío para la carga local.
No se ha ejecutado la importación completa de los ficheros ATOM.
