# Release 8.0.0

## Motivo de la versión mayor

La importación incorpora un modelo de operación y diagnóstico renovado. La consola, los logs técnicos y los correos de soporte ofrecen información estable, trazable y adecuada a cada destinatario.

## Consola de importación

- La salida muestra hora, nivel y mensaje, sin clases Java, números de línea, identificadores internos ni trazas.
- La preparación se resume en una línea con origen, tipo, filtros, modo de actualización e históricos rechazados.
- Cada feed se presenta por nombre y, debajo, se muestran sus contadores de entradas y bajas.
- Los avisos de ficheros locales usan solo el nombre del fichero.
- Se eliminaron encabezados, bloqueos distribuidos, datos de configuración redundantes y cierres genéricos que no aportaban información al operador.
- Los errores muestran una explicación operativa y remiten al log técnico de esa ejecución.

## Gestión de errores

- Las incidencias se clasifican mediante categorías estables: base de datos, configuración, bloqueo, navegación de feeds, XML ATOM, conectividad remota y persistencia.
- La clasificación prioriza tipos de excepción, SQLState de MariaDB y fase del pipeline. El análisis de texto se conserva únicamente para compatibilidad con errores heredados.
- Un error de importación escribe una sola traza completa en el log técnico. Se eliminaron duplicados de las capas de Hibernate, servicio, parseo, JAXB, descarga, Excel y persistencia.
- Un fallo durante rollback conserva una traza separada porque representa un segundo incidente.
- Los logs se individualizan por ejecución y mantienen archivos diferenciados para progreso, errores e Hibernate.

## Soporte por correo

- El correo de error identifica la categoría estable del incidente, fase del pipeline, tipo de sindicación, número y nombre del feed.
- Conserva la causa técnica y la pila configurada para soporte, con redacción de contraseñas, tokens y secretos.
- No se incluyen rutas locales ni URLs completas en el correo.

## Documentación

- Se incorporan la auditoría y el plan de mejora de mensajes y trazas en docs/auditorias.
- El README explica la operación de los scripts, la confirmación no interactiva, configuración, logs y las pautas de diagnóstico.

## Validación

- Suite Maven: 78 pruebas superadas.
- Dos pruebas de integración MariaDB se omiten cuando no hay una conexión de integración configurada.
