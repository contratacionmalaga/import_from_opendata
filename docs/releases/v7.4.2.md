# Release 7.4.2

## Resumen previo de importación

`importar_atoms.ps1` sustituye el bloque genérico **Consecuencias** por un resumen condicionado a los parámetros de la línea de comandos.

- Identifica la base de datos de destino, el usuario configurado y el fichero de conexión sin exponer la contraseña.
- Enumera cada bloque planificado con su grupo, modo, tipo, origen ATOM, JAR y el valor de `app.tipo_sindicacion` que se aplicará.
- Para `local`, informa únicamente de la lectura del ATOM local y de la comprobación de datos existentes.
- Para `internet`, informa del comportamiento incremental y de los reintentos HTTP configurados.
- Muestra filtros solo cuando interviene `con_filtros`; para `sin_filtros` confirma que no se usan.
- Expone los valores efectivos de esquema Hibernate, lote, conexiones, estadísticas, Java, persistencia de rechazos y email.

## Validación

- Análisis sintáctico del script con el parser de PowerShell.
- Prueba de humo cancelada antes de Java para `sin_filtros / local / MAYORES`, comprobando que no aparecen parámetros de internet ni de filtros.
- Prueba de humo aislada para `con_filtros / internet / MAYORES`, comprobando que solo se informa del comportamiento incremental y de los filtros aplicados.
- Pruebas Maven y empaquetado de los cuatro perfiles de ejecución.
